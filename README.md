# Pelican FPS — projeto Android

Painel de recomendações seguras para melhorar a estabilidade do Roblox no Android.

## O que faz
- Abre configurações de bateria e tela do Android.
- Mostra orientações de gráficos, aquecimento e rede.
- Não injeta código, não altera arquivos do Roblox e não exige root.

## Limitação importante
Este projeto não é um desbloqueador real do limite de FPS do Roblox. Um app Android comum não pode garantir 90/120/144 FPS em outro aplicativo. A taxa real depende do Roblox, da experiência, do hardware, da tela e do sistema.

## Como gerar o APK
1. Instale o Android Studio em um computador.
2. Abra a pasta `PelicanFPS_Android`.
3. Aguarde a sincronização do Gradle.
4. Use **Build > Build APK(s)**.
5. O APK de depuração será criado em `app/build/outputs/apk/debug/`.

Requer Android Studio com suporte a Android Gradle Plugin 8.7.3 e SDK 35.
